## `$ whoami`

I'm a **B.Tech Computer Science student focused on Data Science** who likes turning ideas into working software. My projects explore agentic AI, LLM-powered applications, workflow automation, computer vision, and robotics.

My main interest is in systems that go beyond a text response: **retrieving context, calling tools, keeping state, and connecting models to real workflows.**

- 🤖 **Agentic AI:** tool use, multi-agent workflows, RAG, streaming, and memory
- ⚙️ **Automation:** APIs, MCP integrations, and event-driven utilities
- 👁️ **Computer vision:** detection, tracking, and image/video processing
- 🦾 **Robotics:** simulation and industrial automation concepts
