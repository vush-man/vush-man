## `$ whoami`

I'm a **B.Tech Computer Science student focused on Data Science** who enjoys taking ideas from rough prototypes to working software. My work spans agentic AI, LLM-powered apps, workflow automation, computer vision, and robotics.

I'm especially interested in systems that **retrieve context, use tools, preserve state, and help get real work done** — not just generate text.

- 🤖 **Agentic AI:** tool-using agents, multi-agent workflows, RAG, streaming, and memory
- ⚙️ **Automation:** APIs, workflow orchestration, MCP, and event-driven utilities
- 👁️ **Computer vision:** object detection, tracking, and image/video processing
- 🦾 **Robotics:** robot simulation and industrial automation concepts
- 🧪 **How I build:** prototype, test, debug, document, repeat
