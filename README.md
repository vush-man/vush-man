## `$ whoami`

I'm a **B.Tech Computer Science student focused on Data Science** who enjoys taking ideas from rough prototype to working software. My work spans agentic AI, LLM-powered apps, workflow automation, computer vision, and hands-on robotics.

I'm especially interested in systems that don't just generate text — they **retrieve context, use tools, preserve state, and help get real work done**.

- 🤖 **Agentic AI:** tool-using agents, multi-agent workflows, RAG, streaming responses, and memory
- ⚙️ **Automation & integration:** APIs, workflow orchestration, MCP, and event-driven utilities
- 👁️ **Computer vision:** object detection, tracking, and image/video processing
- 🦾 **Robotics:** exploring robot simulation and industrial automation concepts
- 🧪 **Builder mindset:** prototype, test, debug, document, repeat
